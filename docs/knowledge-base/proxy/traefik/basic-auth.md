# Basic Auth

This guide covers how to add HTTP basic authentication to your applications using the Traefik `basicauth` middleware in Coolify.

The setup differs slightly between [Standard Applications](#standard-applications) and [Docker Compose](#docker-compose-and-services) deployments.

## Generating Credentials

Use the `htpasswd` command to generate a bcrypt-hashed password:

```bash
htpasswd -nbB <username> <password>
```

The output looks like:

```
myuser:$2y$12$ci.4U63YX83CwkyUrjqxAucnmi2xXOIlEF6T/KdP9824f1Rf1iyNG
```

Use this string as the value for the `basicauth.users` label below.

::: info
`htpasswd` is part of the `apache2-utils` package on Debian/Ubuntu. Install it with `apt install apache2-utils`.
:::

## Standard Applications

For standard (non-Docker Compose) applications, configure the middleware in the **Container Labels** section in Coolify.

1. Open your application in Coolify and scroll to the **Container Labels** section.
2. Uncheck **Readonly labels** to make the label textarea editable.
3. Add the middleware definition label:

   ```bash
   traefik.http.middlewares.<middleware-name>.basicauth.users=<username>:<hashed-password>
   ```

4. Find the existing `traefik.http.routers.https-0-<uuid>.middlewares=...` line and **append** your middleware name:

   ```bash
   traefik.http.routers.https-0-<uuid>.middlewares=gzip,<middleware-name>
   ```

5. Save and redeploy.

::: warning Important
When you uncheck **Readonly labels**, Coolify stops auto-generating labels on deploy. Use **Reset Labels to Defaults** to restore them if needed.
:::

### Example

```bash
traefik.http.middlewares.my-basicauth.basicauth.users=myuser:$2y$12$ci.4U63YX83CwkyUrjqxAucnmi2xXOIlEF6T/KdP9824f1Rf1iyNG
traefik.http.routers.https-0-abc123.middlewares=gzip,my-basicauth
```

::: info
The `<uuid>` in the router name is generated by Coolify. Find it in your existing Container Labels.
:::

## Docker Compose and Services

For Docker Compose deployments, define the middleware label in your `docker-compose.yml` and use the `coolify.traefik.middlewares` shorthand to attach it to the router automatically.

```yaml
services:
  myapp:
    image: nginx:alpine
    labels:
      - "traefik.http.middlewares.my-basicauth.basicauth.users=myuser:$$2y$$12$$ci.4U63YX83CwkyUrjqxAucnmi2xXOIlEF6T/KdP9824f1Rf1iyNG"
      - "coolify.traefik.middlewares=my-basicauth" # [!code focus]
```

::: warning
In Docker Compose YAML, dollar signs (`$`) must be escaped as `$$` to prevent Docker from interpreting them as environment variable references. This affects bcrypt hashes, which contain `$` characters.
:::

## Troubleshooting

- **Browser keeps prompting for credentials** — verify the password hash was generated with `htpasswd -nbB` (bcrypt flag). MD5 hashes (default without `-B`) may not work correctly.
- **Middleware not applied** — make sure you appended the middleware name to the router's `middlewares` label. Defining the middleware alone is not enough.
- **`$` signs stripped or broken** — enable **Escape special characters in labels** in the Container Labels section, or escape `$` as `$$` in Docker Compose YAML.

For more details on applying custom middlewares, see the [Custom Middlewares](/knowledge-base/proxy/traefik/custom-middlewares) guide.
