# Infrastructure commands

| Command group | Purpose |
| :--- | :--- |
| `server` | Add, inspect, update, validate, provision, and remove servers. |
| `destination` | Manage Docker network destinations. |
| `cloud-token` | Manage provider API tokens used for server provisioning. |
| `s3` | Manage S3-compatible storage destinations. |
| `cloud-init` | Manage cloud-init scripts. |

The `server` group also contains commands for destinations, Cloudflare Tunnel, Docker cleanup, log drains, the reverse proxy, Sentinel metrics, and Hetzner, DigitalOcean, or Vultr provisioning.

```sh
coolify server list
coolify server get <server-uuid>
coolify server validate <server-uuid>
coolify destination list --server <server-uuid>
```

Run `coolify server --help` and then the selected nested command's help before provisioning or removing infrastructure.
