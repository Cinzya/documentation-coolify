# Application commands

Use `coolify app` to manage applications. The aliases `apps`, `application`, and `applications` select the same command group.

| Command | Purpose |
| :--- | :--- |
| `app list`, `app get` | List applications or inspect one by UUID. |
| `app create`, `app update`, `app clone`, `app move` | Create or change an application and its location. |
| `app start`, `app stop`, `app restart`, `app delete` | Control or remove an application. |
| `app logs` | Read or follow application logs and select a Docker Compose service. |
| `app env` | List, get, create, update, delete, or sync environment variables. |
| `app storage` | Manage persistent and file storage. |
| `app deployments` | List application deployments and read deployment logs. |
| `app previews` | Manage preview deployments. |
| `app task`, `app execute-task` | Manage scheduled tasks and run one immediately. |
| `app tag`, `app destinations` | Manage tags and additional destinations. |
| `app rollback`, `app run-storage-backup` | Use rollback helpers or run a configured volume backup. |

Run help at the relevant level before changing or deleting an application:

```sh
coolify app create --help
coolify app update --help
coolify app delete --help
```
