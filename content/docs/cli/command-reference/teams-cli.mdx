# Team and CLI utility commands

| Command group | Purpose |
| :--- | :--- |
| `teams` | List teams, inspect a numeric team ID, show the token's current team, and list members. |
| `context` | Add, list, update, verify, select, and delete saved Coolify connections. |
| `config` | Print the CLI configuration file path. |
| `completion` | Generate completion for Bash, Zsh, Fish, or PowerShell. |
| `version` | Print the installed CLI version. |
| `update` | Download and install the latest compatible CLI release. |

Use [Authentication](/cli/authentication) for token setup and [Contexts](/cli/contexts) for saved connection management. Follow [Update](/cli/update) for update methods and verification.
