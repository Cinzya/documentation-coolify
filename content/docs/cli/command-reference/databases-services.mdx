# Database and service commands

## Databases

Use `coolify database`, `databases`, `db`, or `dbs`.

| Command | Purpose |
| :--- | :--- |
| `database list`, `database get` | List databases or inspect one by UUID. |
| `database create`, `database update`, `database clone`, `database move` | Create or change a database and its location. |
| `database start`, `database stop`, `database restart`, `database delete` | Control or remove a database. |
| `database logs` | Read or follow database logs. |
| `database backup` | Manage database backup configurations and executions. |
| `database env`, `database storage`, `database tag` | Manage variables, storage, and tags. |
| `database run-storage-backup` | Run a configured volume backup immediately. |

## One-click services

Use `coolify service`, `services`, or `svc`.

| Command | Purpose |
| :--- | :--- |
| `service list`, `service get`, `service create` | Inspect or create one-click services. |
| `service start`, `service stop`, `service restart`, `service delete` | Control or remove a service. |
| `service clone`, `service move` | Copy a service or move it to another environment. |
| `service logs` | Read logs for a service sub-resource. |
| `service application`, `service database` | Manage applications and databases inside a service. |
| `service env`, `service storage`, `service tag` | Manage variables, storage, and tags. |
| `service task`, `service execute-task` | Manage scheduled tasks and run one immediately. |
| `service run-storage-backup` | Run a configured service volume backup. |

Run `coolify database <command> --help` or `coolify service <command> --help` for required resource UUIDs and flags.
