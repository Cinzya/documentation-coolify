# CLI command reference

The command reference groups related Coolify CLI commands by the resources and operations they manage. Use it to find the relevant command group, then run the installed CLI's help for its exact arguments and flags.

## Global flags

| Flag | Purpose |
| :--- | :--- |
| `--context <name>` | Use a saved context for one command instead of the default. |
| `--token <token>` | Override the selected context's token for one command. |
| `--format table\|json\|pretty` | Choose human-readable table output, compact JSON, or indented JSON. |
| `--show-sensitive`, `-s` | Display sensitive values when the token has permission. |
| `--debug` | Print additional diagnostic output. |
| `--help`, `-h` | Show help for the current command level. |

## Discover nested commands

Help is available at every level:

```sh
coolify database --help
coolify database backup --help
coolify database backup create --help
```

The built-in help is authoritative for the installed CLI version. The [Coolify CLI repository](https://github.com/coollabsio/coolify-cli) contains release notes and generated command catalogs.
