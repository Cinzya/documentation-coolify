# Remove a server

Removing a server from Coolify removes its server details from the database. It does not uninstall Docker or delete files on the Linux server.

The **localhost** server of a self-hosted Coolify installation cannot be removed.

## Remove the server from Coolify

<Steps>
<Step>

### Review the server Resources page

1. Open **Servers** in the Coolify sidebar.
2. Select the server you want to remove.
3. Open **Resources** page.
4. Select **Managed**.
5. Review every resource listed on the page.

Decide what should happen to each resource before removing the server:

- Create backups of important application and database data.
- Redeploy or recreate resources you want to keep on another server.
- Delete resources you no longer need.
- Update DNS records after redeploying resources on another server.

<Callout type="error" title="Remove managed resources first">
Do not remove the server while the **Managed** tab still lists resources. Back up important data, then redeploy each required resource elsewhere or delete it before continuing.
</Callout>

</Step>
<Step>

### Open the server Danger Zone

After the **Managed** tab shows **No managed resources found**:

1. Select **Danger** in the server sidebar.
2. Find **Delete Server** under **Danger Zone**.

</Step>
<Step>

### Remove the server

1. Select **Delete**.
2. Confirm that the dialog says the server will be permanently deleted from Coolify.
3. Enter the server name exactly as shown.
4. Enter your Coolify account password.
5. Complete the confirmation.

Coolify returns to the **Servers** page after the server is removed.

</Step>
<Step>

### Confirm the removal

Check that the server no longer appears on **Servers** page.

Removing server from Coolify does not remove Docker, application files, or other data that may remain on the machine.

</Step>
</Steps>

---

## Add the server again

There is no restore button for a removed server.

<Callout type="warning" title="Re-adding the server does not restore its resources">
Applications, databases, and services that were previously deployed to the server do not return to the Coolify dashboard when you add the server again, even if their containers or files still remain on the machine.

Removing the server deletes the relationships in Coolify that connected those resources to the server. Adding the same machine again creates a new server on database without those relationships.
</Callout>

If the Linux machine still exists, follow [Add Server](/core/servers/add-server) and enter its current IP address, SSH port, user, and private key. Validate the server, then recreate or redeploy each resource you want Coolify to manage.
