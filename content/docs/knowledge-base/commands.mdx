# Commands

## Recover the root account

Use the complete recovery guides for the root account commands. Each guide includes prerequisites, consequences, verification, and failure recovery:

- [Reset Root Password](/core/backup-and-recovery/reset-root-password)
- [Change Root Email](/core/backup-and-recovery/change-root-email)

## Delete a stuck service

Connect to the server that runs Coolify over SSH, then run:

```sh
docker exec -it coolify php artisan services:delete
```
